## 📖 About the Project
## 🎯 Why I Created This Project
As a 1st-year Computer Science student, I built this project to deepen my understanding of programming fundamentals. My main goals were:

* **To Master Control Flow:** I wanted to practically implement and compare **`for`** and **`while`** loops to understand their syntax and behavior differences.
* **To Analyze Efficiency:** By counting iterations, I wanted to see "behind the scenes" of how the computer executes code step-by-step.
* **Logic Building:** Converting time units manually helped improve my problem-solving logic.
*
This C program is a logic-building exercise designed to convert **Total Seconds** into a standard time format (**Hours : Minutes : Seconds**). 

Instead of just calculating the time, this project demonstrates **Control Flow** concepts by solving the problem in two different ways:
1.  **Using a For Loop**
2.  **Using a While Loop**

The program counts the **iterations** (steps) each loop takes to complete the task and compares the results. This helps in understanding how different loops function and serves as a practical introduction to algorithm efficiency.

## 💡 Utility (Why is this useful?)
This project serves several practical purposes for a computer science student:

* **Educational Tool:** It is a hands-on way to master **Loop Control Structures** in C programming.
* **Logic Verification:** By comparing two different loops, it acts as a self-checking system to ensure the logic is bug-free.
* **Performance Analysis:** Counting iterations introduces the concept of **Time Complexity**, showing exactly how much work the processor does for a specific task.
* **Practical Conversion:** It functions as a working calculator for converting large second values into human-readable time.
